> **課程名稱**：萬能科技大學《創意發想與實踐》（11501）

## 專案核心理念
針對單身族、租屋族與大學生「一人吃韓式料理難開鍋、客單價偏高、外送冷掉軟爛」之核心痛點，打造「百元平價、一人獨享、3分鐘道地」的微型韓食品牌。透過手工現捲麻油飯捲、天然果釀發酵泡菜與獨享 DIY 辣炒年糕調理包，在極低初始成本（3~5萬內）下達成微型創業驗證。

## 學理分析重點摘要
1. **痛點發掘**：一人用餐開鍋難度高、市售調理包添加劑過多、外送高抽成與冷硬問題。
2. **PESTC 掃描**：落實 GHP 食品法規信任、掌握抗通膨口紅效應、契合追劇一人食文化、低成本真空鎖鮮科技、在地食材減碳。
3. **SWOT 四部曲**：SO（校園社群積極開拓）、WO（限量預約轉化產能劣勢為稀缺性）、ST（手工果釀食材履歷對抗低價工業品）、WT（聚焦三款明星品精實避險）。
4. **SMART 目標**：30 天內獲得 250 次點擊、收集 35 筆預購意向。
5. **STP & 4P 方案**：定位為一人份無負擔手作道地韓味；主打「麻香飯捲 NT$110」、「手工泡菜 NT$160」、「年糕DIY包 NT$130」與「首爾狂熱一人吃飽三件組特惠 NT$369」。
